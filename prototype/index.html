Why it looks like this

      
    
        
  • Mods can draw a pane, a band above the prompt, toasts, a status line, and can redraw tool rows and the spinner. Orchestra uses only those places. Mods interface docs
    • 
        
  • Subagents return only a final message to the conductor, so Orchestra records reads and writes per agent from tool events instead of trusting summaries. Subagents docs
    • 
        
  • Conflicts and stale reads are derived from which version each musician read before writing, not declared by the agents.
    • 
        
  • The conductor asks you through the question dialog, the same place Claude Code asks questions.
